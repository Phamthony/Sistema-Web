Desarrollo de una aplicación web utilizando C#, ASP.NET MVC y SQL Server como proyecto universitario.

Funcionalidades implementadas:

Autenticación de usuarios y control de acceso según roles (administrador y empleado).

Gestión de empleados: creación, consulta, edición y eliminación de registros.

Búsqueda y filtrado de empleados por categoría.

Cálculo de nómina diaria basado en las horas trabajadas y la información salarial.

Exportación de registros de empleados a Excel.

Generación de reportes de nómina en PDF.

Tecnologías: C#, ASP.NET MVC, SQL Server, HTML, CSS, Bootstrap, JavaScript, jQuery, AJAX y JSON.

Conocimientos aplicados: programación orientada a objetos, desarrollo backend, bases de datos relacionales y lógica de negocio.
